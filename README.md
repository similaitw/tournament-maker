# 賽事大師｜對戰樹與即時積分

繁體中文的賽事管理網站：建立賽事、自動產生對戰樹與賽程、輸入比分即時更新積分榜。

網站：https://tournament-maker-chi.vercel.app

## 功能
- 賽制：單淘汰（可加季軍戰）、雙淘汰（勝部／敗部、總決賽重賽）、循環賽（單／雙循環）、瑞士制、分組循環＋淘汰賽
- 非 2 的次方隊數自動安排輪空；淘汰賽平手可判定晉級方
- 即時積分榜（積分 → 得失分差 → 總得分；瑞士制含 Buchholz）、近五場戰績
- 賽程表：日期／時間／場地、自動排程、篩選與搜尋
- 大螢幕模式、隊伍個人戰績頁、JSON 匯出／匯入

## 雲端儲存（Vercel Blob）
- 賽事資料存在 Vercel Blob 私人儲存區（`api/t.js`），換裝置也能同步
- 每個賽事有兩種連結：
  - **觀看連結**：任何人可看，每 8 秒自動更新，不能修改
  - **管理連結**：含管理金鑰（伺服器只存雜湊值），持有者才能修改
- 需要環境變數 `BLOB_READ_WRITE_TOKEN`（在 Vercel 連接 Blob store 後自動產生）
- 沒有雲端 API 時（例如直接開啟 HTML 檔），自動改用瀏覽器 localStorage

## 檔案
- `index.html`：整個前端（無需建置）
- `api/t.js`：讀寫賽事的 Serverless Function
