# 賽事大師｜對戰樹與即時積分

繁體中文的賽事管理網站（運動、電競、棋藝、知識搶答、辯論等皆適用）：建立賽事、自動產生對戰樹與賽程、輸入比分即時更新積分榜。

網站：https://tournament-maker-chi.vercel.app

## 功能
- 賽制：單淘汰（可加季軍戰）、雙淘汰（勝部／敗部、總決賽重賽）、循環賽（單／雙循環）、瑞士制、分組循環＋淘汰賽
- 非 2 的次方隊數自動安排輪空；淘汰賽平手可判定晉級方
- 即時積分榜（積分 → 得失分差 → 總得分；瑞士制含 Buchholz）、近五場戰績
- **場地設定**：場地數量、名稱，分組賽可選「有空就排」或「各組固定場地」
- **自動排程**：分組循環賽各組交叉排（第 1 輪 A、B、C 組輪流）、同一參賽者不會同時兩場、盡量不連續上場、淘汰賽等前一輪結束；場次編號依實際比賽時間
- 賽程表：依時間清單或**場地表**（時段 × 場地），篩選與搜尋
- **樹狀圖**（淘汰賽，直式／橫式，紅線標出勝出路線）與**多邊形圖**（循環賽，線上標場次、顏色代表輪次），可下載 PNG／SVG 或列印
- 大螢幕模式、隊伍個人戰績頁、JSON 匯出／匯入

## 權限
| 角色 | 取得方式 | 可以做什麼 |
|---|---|---|
| 👑 主辦 | 建立賽事的裝置；或「🔑 登入管理」輸入主辦密碼；或主辦管理連結 | 全部：參賽者、設定、比分、刪除、權限管理 |
| 📝 計分員 | 「🔑 登入管理」輸入計分員密碼（主辦在設定中開放） | 輸入比分、安排時間、產生下一輪 |
| 👀 觀眾 | 打開觀看連結 | 只能看，每 8 秒自動更新 |

- 權限由伺服器把關：計分員送出的資料若改到比分／賽程以外的欄位會被拒絕
- 建立賽事時必須設定主辦密碼；可在這台裝置登出、以「觀眾視角」預覽（投影時避免誤觸）
- 「重設所有權限」：舊連結、密碼、計分員全部失效
- 密碼不保存明碼：以 scrypt 推導金鑰，用 AES-256-GCM 加密管理金鑰

## 超級管理後台（網址加上 `#admin`）
- 以環境變數 `ADMIN_PASSWORD` 的超級管理密碼登入（12 小時有效）
- 賽事總覽：名稱、賽制、進度、來源建立碼、最後更新、大小；可刪除、可替忘記密碼的主辦**重設主辦密碼**
- **建立碼**：開啟後必須輸入有效建立碼才能建立新賽事（伺服器端檢查），可新增／停用／刪除並記錄使用次數
- **自動清理**：超過設定天數未更新的賽事，每天凌晨 3 點（台灣時間）由 Vercel Cron 刪除（需 `CRON_SECRET`）

## 雲端儲存（Vercel Blob）
- 賽事資料存在 Vercel Blob 私人儲存區（`api/t.js`），換裝置也能同步
- 環境變數：`BLOB_READ_WRITE_TOKEN`（連接 Blob store 後自動產生）、`ADMIN_PASSWORD`（超級管理密碼，自行設定）、`CRON_SECRET`（排程驗證）
- 沒有雲端 API 時（例如直接開啟 HTML 檔），自動改用瀏覽器 localStorage；範例賽事只存在本機

## 檔案
- `index.html`：整個前端（無需建置）
- `api/t.js`：讀寫賽事、權限
- `api/admin.js`：超級管理後台
- `api/_lib.js`：共用工具（加密、儲存）
- `vercel.json`：自動清理排程
